# 스토어메이커 상세페이지를 Figma에서 열기

1. 스토어메이커에서 상세페이지 또는 광고 세트를 만든 뒤, 결과 화면의 **피그마용 파일 받기**를 누릅니다. 광고 세트는 작업 기록에서 이전 결과를 다시 열어도 됩니다.
2. Figma 디자인 파일에서 메뉴 → Plugins → Development → Import plugin from manifest…를 선택하고 이 폴더의 `manifest.json`을 엽니다. 최초 한 번만 필요합니다.
3. Plugins → Development → **Store Maker 상세페이지 가져오기**를 실행합니다.
4. 받은 JSON 파일을 선택하고 **상세페이지 만들기**를 누릅니다.

현재 Figma 페이지에 860px 프레임이 추가됩니다. 웹앱의 디자인 정보에 포함된 글자, 도형, 그라디언트, 사진이 별도 요소로 만들어집니다. 광고 세트는 모든 사진을 세로로 연결하고 사진 위 제목과 그라디언트, 사진 아래 본문과 버튼 문구를 분리합니다. 디자인 정보가 없는 기존 상세페이지 섹션은 문구 카드와 사진으로 표시됩니다. 이미 이미지에 그려진 글자나 장식은 분리되지 않습니다. 폰트가 없으면 사용 가능한 대체 글꼴을 사용합니다.
